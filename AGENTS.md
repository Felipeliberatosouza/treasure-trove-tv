- Text AI model per area is read at runtime from `platform_settings.ai_models_config` via `supabase/functions/_shared/ai-models.ts` (`resolveModel`), defaulting to `openai/gpt-6-astra`; why: admin switches providers per area without code changes.
- Narration voice provider comes from `platform_settings.ai_voice_config`; ElevenLabs (`with-timestamps`) stores per-character timing in the audio artifact metadata, which drives avatar visemes (`src/utils/phonemeLipSync.ts`) and captions, with automatic OpenAI TTS fallback; why: lip-sync needs real timing and students must never lose audio.
- Default lessons use illustrated rigged teachers (`RiggedAvatar`) driven by ElevenLabs visemes; real-person lip-sync only exists for admin-chosen special lessons rendered externally by `neural-avatar-render` (artifact type `neural_video`, played muted and slaved to the narration audio); why: canvas deformation of real video produced visible artifacts.
